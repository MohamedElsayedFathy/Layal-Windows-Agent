# خطة الاختبارات الآلية — Layal 0.5.2

## الهدف
إضافة اختبارات انحدار قابلة للتكرار حتى لا نعتمد على وجود الكود أو واجهة المستخدم وحدهما لإثبات صحة الوظيفة.

## الحزم الاختبارية

- `SettingsStoreTests`: القيم الافتراضية، تطبيع اللغة والإعدادات خارج النطاق، الحفظ/الاسترجاع، والتعافي من JSON تالف.
- `SkillPackageServiceTests`: استيراد ZIP صالح، قراءة `SKILL.md` بحد أحرف، رفض الاسم المكرر دون موافقة، رفض YAML/اسم غير صالح، غياب `SKILL.md`، ورفض روابط GitHub غير صحيحة قبل الاتصال بالشبكة.
- `MemoryServiceTests`: رفض محتوى يبدو سرًا قبل الحفظ، البحث الفارغ، ودورة حفظ/بحث/تعديل/حذف باستخدام DPAPI. اختبارات DPAPI يجب أن تعمل على Windows وبحساب اختبار عادي.
- `AgentToolExecutorTests`: تفرد أسماء الأدوات، عمل أداة وقت محلية، رفض traversal، عدم إنشاء ملف عند رفض الموافقة، إنشاء ملف بعد الموافقة، منع الاستبدال، ورفض ملف غير مشروع قبل طلب موافقة البناء.
- `OpenAiCompatibleClientTests`: بناء `/models` و`/chat/completions`، رأس Bearer، تحليل رد المحادثة، تحليل tool call، رفض الرسائل الفارغة وعناوين URLs غير الآمنة. يتم استخدام `HttpMessageHandler` مزيف؛ هذه الاختبارات لا تتصل بمزود حقيقي ولا تثبت توافق كل مزود.

## تشغيل الاختبارات على Windows

```powershell
dotnet restore Layal.sln
dotnet build Layal.sln --configuration Release --no-restore
dotnet test Layal.sln --configuration Release --no-build --no-restore --logger "trx;LogFileName=Layal.Tests.trx" --results-directory artifacts/test-results
```

أو شغّل `powershell -ExecutionPolicy Bypass -File .\tools\VERIFY-LAYAL.ps1`. بعد الاختبارات، يتأكد `tools/validate_test_results.py` من وجود تقارير TRX وعدد اختبارات أكبر من صفر.

## ما لا تغطيه هذه الاختبارات بعد

- التشغيل المرئي لنافذة WPF والعائمة والشاشات المتعددة.
- تقييم دقة الصوت العربي/المصري أو النص إلى كلام.
- اختبار مزود API حقيقي واختلاف دعم tool calling بين النماذج.
- اختبار أجهزة كاميرات RTSP/ONVIF حقيقية.
- أتمتة DOM في المتصفح، تكامل MCP، وتدريب النماذج.
- تثبيت/ترقية/إزالة التطبيق.
- اختبارات أمن معمقة للعزل أو إعادة توجيه النظام/نقاط الوصل على Windows.

## عدد الاختبارات الحالية

يوجد 27 اختبارًا ضمن خمس مجموعات. هذا العدد يصف الاختبارات المكتوبة، وليس عدد الاختبارات الناجحة؛ لا توجد نتيجة تنفيذ حتى الآن.

## حالة التنفيذ الحالية

الاختبارات مكتوبة ومضافة إلى الحل وCI. لم تُشغّل من بيئة التأليف لأنها لا تحتوي على .NET SDK، لذا لا توجد نتائج نجاح/فشل فعلية حتى الآن. لا تحدّث حالة متطلب الاختبارات إلى "متحقق" إلا بعد نجاح Windows CI ومراجعة أي فشل.
