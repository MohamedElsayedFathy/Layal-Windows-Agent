# قبول AYO-08 — OCR محلي للصور وPDF الممسوح

## طريقة التشغيل

يستخدم Layal محرك Tesseract محليًا مع نموذجي اللغة العربية والإنجليزية. لا يعتمد هذا المسار على Windows.Media.Ocr أو MSIX أو تثبيت حزم OCR في Windows. لا يلزم اتصال إنترنت وقت التعرف بعد تثبيت Layal؛ تنزيل النماذج يتم أثناء بناء التوزيعة فقط.

من جذر المستودع، حمّل النماذج ذات الإصدارات المثبتة وتحقق من سلامتها:

```powershell
pwsh -NoProfile -ExecutionPolicy Bypass -File .\tools\Install-LayalOcrModels.ps1
```

ثم ابنِ التطبيق:

```powershell
dotnet build Layal.sln --configuration Release
```

## ما يدعمه المسار

- صور PNG وJPG/JPEG وBMP وTIFF، بما فيها إطارات TIFF المتعددة بحد أقصى 25 إطارًا.
- PDF ذو طبقة نصية: يستخرج النص الرقمي أولًا، ثم يحاول OCR للصور المضمّنة في الصفحات؛ وبذلك لا تختفي الصور الممسوحة داخل PDF مختلط.
- PDF ممسوح بلا طبقة نصية: يحاول OCR للصور المضمّنة بدل رفض الملف لمجرد غياب النص.
- اللغتان العربية والإنجليزية في جلسة OCR واحدة، محليًا ودون إرسال إلى مزود AI.

## حدود السلامة والموارد

- 20 MiB كحد أقصى لحجم الملف.
- 25 صفحة PDF و25 إطار صورة كحد أقصى.
- 8 ملايين بكسل و3,000 بكسل لكل ضلع بعد التطبيع.
- 8 صور مضمّنة كحد أقصى لكل صفحة PDF.
- 10,000 حرف كحد أقصى للنص المستخرج.
- لا تُنفّذ وحدات ماكرو ولا تعليمات مستخرجة من الوثيقة.
- تُصفّر مصفوفات البايتات المؤقتة للصورة بعد اكتمال OCR أو فشله أو إلغائه.
- لا يُرفق النص إلا بعد عرض معاينة صريحة؛ ولا يُرسل للمزود إلا عندما يضغط المستخدم زر إرسال.
- لا يمكن إيقاف استدعاء Tesseract الأصلي في منتصف الصفحة بأمان؛ الإلغاء يُفحص بين الإطارات/الصفحات وبعد عودة الاستدعاء الجاري.

قد لا يستخرج PdfPig صور PDF التي تستخدم مرشحات غير مدعومة أو صورًا مرسومة كمسارات متجهية؛ تُعرض رسالة توضح أن الصفحة لم تُقرأ بدل الادعاء بنجاح OCR. لا يُضمن OCR للمخطوطات اليدوية أو الصور المائلة بشدة أو الجداول المعقدة أو الأرقام الصغيرة.

## مصفوفة القبول اليدوي المطلوبة

1. صورة عربية واضحة، وصورة إنجليزية واضحة، وصورة تجمع اللغتين في الصفحة نفسها.
2. صورة هاتف مائلة قليلًا، وصورة منخفضة التباين، وصورة صغيرة النص؛ سجّل الأخطاء ولا تفترض الدقة.
3. ملف TIFF متعدد الإطارات، مع التأكد من ظهور فواصل الإطارات.
4. PDF ممسوح متعدد الصفحات، وPDF مختلط يحتوي صفحة رقمية وصفحة مصورة وصفحة تجمع الاثنين.
5. تحقق من ترتيب الصفحات وأسماء الصفحات والأرقام والتواريخ واتجاه RTL مقابل مرجع ذهبي.
6. أوقف OCR أثناء ملف متعدد الصفحات، وتأكد من عدم إرفاق نتيجة جزئية أو إرسال أي محتوى.
7. جرّب غياب أحد النموذجين، ملفًا تالفًا، صورة كبيرة جدًا، وPDF مشفرًا أو يستخدم مرشح صورة غير مدعوم.
8. أرفق النص بعد مراجعته ثم أزله قبل الإرسال؛ يجب ألا يبقى محتوى OCR معلّقًا.

نجاح CI يثبت عمل المحرك المحلي على عينات التكامل، لكنه لا يثبت دقة كل خط أو ماسح ضوئي أو جودة تصوير. سجّل نتائج العينات الحقيقية قبل إغلاق بوابة القبول اليدوي.
