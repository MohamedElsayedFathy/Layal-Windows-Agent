# Layal 0.5.2 — ملاحظات إصدار مرشّح (مسودة غير منشورة)

> **الحالة: UNRELEASED / DRAFT.** هذه ملاحظات مرشّح إصدار للتحضير والمراجعة فقط. ليست إعلان إصدار عام، ولا تعني أن التوقيع أو القبول اليدوي أو المراجعة القانونية اكتملت.

## ملخص

يواصل Layal 0.5.2 تطوير تطبيق مساعد سطح مكتب لنظام Windows باستخدام WPF، مع شخصية عائمة قابلة للتفاعل وواجهة عربية/إنجليزية، وطبقة تخزين محلية محمية بـ Windows DPAPI لبعض بيانات التطبيق.

## ما يتضمنه المرشّح

- واجهة WPF ذات سمة فاتحة وأخرى داكنة، وبنية تنقل متعددة الأقسام.
- شخصية عائمة بإيماءات وحالات تعبيرية متحركة، مع اختبارات أصلية لحدود النقر الشفاف والسحب وحفظ الموضع.
- خيارات واجهة العربية والإنجليزية؛ اكتمال الترجمة وتجربة RTL/LTR لكل العناصر بحاجة إلى مراجعة يدوية.
- عميل متوافق مع واجهات OpenAI، مع دعم استدعاء الأدوات وتدفق عمل محدود يتطلب موافقة على إجراءات ذات أثر.
- مساحة عمل مقيدة نسبيًا لأدوات الملفات وبناء/اختبار مشاريع .NET، واستيراد حزم مهارات ZIP/GitHub وفق التحقق المضمّن.
- حفظ محلي لبعض سجلات المحادثة والمهام والذاكرة عبر تخزين محمي بـ DPAPI.
- مسار بناء Windows x64 ذاتي التشغيل، ومثبّت لكل مستخدم، وحزمة ZIP محمولة، وCycloneDX SBOM وقائمة تبعيات وبصمات SHA-256.

هذه القائمة تصف نطاق المصدر وآلية التوزيع، ولا تؤكد أن كل تكامل اجتاز قبولًا يدويًا أو خدمة خارجية فعلية.

## قيود معروفة قبل النشر

- **هذا المرشّح غير موقع رقميًا.** سجّلت CI أن \`Layal.exe\` و\`Layal.dll\` والمثبّت غير موقّعة لعدم إعداد أسرار شهادة التوقيع. لا توزّع هذا artifact بوصفه إصدارًا رسميًا معتمدًا.
- **القبول على Windows فعلي غير مكتمل.** يلزم اختبار جلسة سطح مكتب حقيقية تشمل Tray والماوس واللغة والثيم وحفظ الإعدادات وDPI والشاشات المتعددة حسب بيئة الهدف.
- **مراجعة الترخيص مفتوحة.** لا توجد رخصة للمشروع نفسه معتمدة بعد، وتحتاج حقوق إعادة توزيع أصول الشخصية والأيقونات ومراجعة تراخيص الطرف الثالث وSBOM إلى إغلاق بشري.
- دورة الرجوع التي اختبرها CI تستخدم fixture اصطناعيًا للإصدار 0.5.1، وليست اختبارًا لمثبت تاريخي حقيقي أو ترحيل بيانات قديمة.
- يعتمد الاتصال الفعلي على endpoint وموديل يدعمان صيغة استدعاء الأدوات المتوافقة؛ اختبارات العميل الآلية لا تثبت توافر خدمة خارجية.
- ميزات المنتج التالية ليست ضمن النطاق المكتمل: STT/TTS صوت فعلي، أتمتة DOM للمتصفح، أتمتة عامة للماوس/لوحة المفاتيح، معالجة RTSP/ONVIF والرؤية الحاسوبية، تنفيذ بروتوكول MCP، وذاكرة RAG/متجهية وتدريب النماذج.
