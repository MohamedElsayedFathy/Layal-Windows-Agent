# الأمان وسلسلة التوريد — Layal

## نقل بيانات مزود الذكاء الاصطناعي والتحقق من مكونات الصوت

- عميل OpenAI-compatible يرفض الآن أي عنوان `http://` لمضيف بعيد قبل إنشاء/إرسال الطلب؛ HTTP مسموح فقط لعناوين loopback المحلية. يشمل ذلك فحص الاتصال والمحادثة والبث والمهام وتحليل الصور لأنها تستخدم منشئ URI مشتركًا. كما تُرفض بيانات الدخول المضمنة وQuery وFragment في Base URL.
- عميل المزود لا يتبع تحويلات HTTP `3xx` تلقائيًا؛ يُعامل رد التحويل كاستجابة من المزود ولا يُعاد إرسال نص المحادثة أو الصور أو معاملات الأدوات إلى وجهة بديلة.
- مسار STT وRealtime TTS كان يفرض HTTPS للمضيف البعيد بالفعل؛ أصبح شرط النقل الآمن متسقًا مع عميل المحادثة.
- نموذج Whisper base يُنزّل من مراجعة ثابتة في Hugging Face مع بصمة SHA-256، وليس من مرجع `main` متغير.
- أرشيف whisper.cpp لويندوز x64 يُتحقق من حجمه وبصمة SHA-256 المثبتة، ويُحتفظ به محليًا كمرجع ثقة. يقارن Layal كل ملف مستخرج، بما فيه `whisper-cli.exe` وملفات DLL، بمحتوى الأرشيف عبر SHA-256، ويرفض الملفات المفقودة أو الزائدة أو الروابط الرمزية. يعاد التحقق قبل إعلان الموارد جاهزة وقبل كل عملية تحويل كلام.
- التحقق يكتشف تلف الملفات أو اختلافها عن المكونات المثبتة؛ ولا يحل محل حماية Windows من برمجيات خبيثة تعمل بصلاحية المستخدم نفسه أو مراجعة كل مكونات الجهاز.
- التثبيتات القديمة التي حذفت أرشيف Whisper بعد الاستخراج ستحتاج تنزيل الأرشيف الصغير مرة واحدة بعد موافقة المستخدم، ثم يُحتفظ به للتحقق اللاحق.

## بوابات آلية

- Directory.Build.props يفعّل NuGet Audit للشجرة الكاملة (NuGetAuditMode=all) ويطلب مستوى تدقيق low، بما يشمل الحزم المتعدية.
- tools/audit_nuget.py يشغّل dotnet package list --vulnerable --include-transitive --format json، ويحفظ التقرير الخام وملخص النتائج، ويفشل إذا ظهرت استشارة ثغرة أو تعذّر تفسير تقرير NuGet.
- tools/validate_licenses.py يقارن مكونات SBOM بجرد رخص محدد، ويرفض المكونات غير المسجلة أو اختلاف الرخصة المعلنة عن الجرد، ويتأكد من وجود نصوص الإشعارات.
- gitleaks/gitleaks-action يفحص نطاق الـ commits الخاص بالتشغيل، ثم يشغّل workflow فحصًا صريحًا ثانيًا عبر Gitleaks CLI مع خيار all على جميع المراجع والتاريخ المتاح في checkout. يُرفع تقرير SARIF للفحص الكامل في artifact مستقل.
- .github/dependabot.yml يطلب تحديثات أسبوعية لاعتماديات NuGet وGitHub Actions؛ لا تُدمج تحديثاته تلقائيًا.
- tools/validate_release.py يحتفظ بفحوص أنماط الأسرار المعروفة، مع التنبيه إلى أن فحص الأنماط وحده ليس ماسح أسرار كاملًا.

## ما يغطيه SBOM

ملف sbom/Layal-<version>.cdx.json هو جرد لتبعيات تطبيق WPF كما تراها أداة CycloneDX في المشروع. تسجل نسخة الإصدار أيضًا إصدار كل حزمة تم حله. يستخدم تدقيق NuGet ملف الحل Layal.sln حتى لا تقتصر مراجعة الثغرات على التبعيات التي تدخل حزمة التطبيق؛ وتدخل تبعيات الاختبارات ضمن تدقيق الثغرات كذلك.

الجرد الحالي يثبت أن بيانات الرخص المنشورة لـ Emoji.Wpf وStfu تشير إلى WTFPL، وبيانات JeremyAnsel.HLSL.Targets تشير إلى MIT. هذه مطابقة بيانات مصدر الحزمة، وليست حكمًا قانونيًا بأن كل استخدام/توزيع متوافق. نصوص الرخص وإشعارات المكونات المعروفة مضمّنة في مجلد licenses داخل حزمة التوزيع.

## بوابات ما زالت مفتوحة

1. رخصة مشروع Layal نفسه غير معلنة؛ يجب أن يحددها صاحب/أصحاب الحقوق. لا تُعامل إشعارات الطرف الثالث كرخصة للمشروع.
2. مصدر وحقوق إعادة توزيع أصول الشخصية والأيقونة لم تُوثق بعد.
3. ما زالت مراجعة بشرية مطلوبة لتوافق الرخص والإشعارات لجميع المكونات والأصول مع النشر العام أو التجاري.
4. فحص Gitleaks وNuGet CI يثبت نتيجة الفحص للـ commit الذي شُغّل عليه فقط؛ لا يثبت أن التطبيق خالٍ من كل عيوب الأمان أو الأسرار التشغيلية.
5. أضيف مسار Authenticode للتوقيع وختم RFC 3161 والتحقق من بصمات الحزمة، لكن التوقيع الفعلي ما زال يتطلب شهادة موثوقة ضمن GitHub Actions Repository Secrets وتشغيل tag ناجح. لا تُعتبر الحزمة موقعة قبل نجاح هذا التشغيل.

لا تُعلن الحزمة جاهزة للنشر العام/التجاري إلى أن تُغلق قرارات الرخص والأصول والتوقيع والقبول اليدوي.

- إصدار Gitleaks CLI مثبت صراحةً على 8.30.1 في الـ workflow، لتجنّب الاعتماد على الإصدار الافتراضي المتغير داخل الـ action.

 
## التوقيع وسلامة ملفات التوزيع

أدوات `tools/Sign-LayalFile.ps1` و`tools/Verify-LayalDistributionIntegrity.ps1` توقّعان التطبيق والمُثبّت عند إعداد الشهادة، وتتحققان من الختم الزمني ومن بصمات جميع الملفات. إصدار tag يبدأ بـ `v` يرفض إنتاج artifact إذا كان التوقيع غير مهيأ أو لم ينجح التحقق. لم تُضبط شهادة فعلية بعد، لذلك يظل هذا متطلبًا مفتوحًا للإصدار العام.
