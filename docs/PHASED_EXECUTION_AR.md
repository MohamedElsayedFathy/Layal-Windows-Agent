# خطة التنفيذ المرحلية — شخصية ليال والمراجعة البصرية

## قواعد التنفيذ
- تُنفّذ مرحلة واحدة فقط في كل مرة.
- بعد اكتمال المرحلة وإظهار نتيجة التحقق، يتوقف العمل إلى أن يوافق المستخدم صراحةً على المرحلة التالية.
- نجاح CI أو توليد صور آلية لا يعني اجتياز اختبار التشغيل على شاشات Windows فعلية.
- يظل PR رقم 6 مسودة، ولا يدمج إلى main قبل اجتياز بوابة القبول المطلوبة.

## المرحلة الأولى — مجسم الشخصية وهيكل التحريك ثلاثي الأبعاد
**الحالة: مكتملة في الفرع من ناحية التنفيذ والبناء والاختبارات الآلية؛ القبول النهائي على جهاز المستخدم ليس مُدّعى.**

- [x] عقدة للرأس، وعقدة للجذع، وعقد مستقلة للذراعين والساقين.
- [x] مفاصل تحويل مستقلة للعضدين والساعدين واليدين والفخذين والساقين والقدمين.
- [x] ملامح وجه ثلاثية الأبعاد: بياض العين والقزحية والبؤبؤ والحواجب والخدود والفم.
- [x] ربط اتجاه البؤبؤ بالماوس، وتغيير مقياس العين للرمش/التعبير، وتبدل شكل الفم والحواجب والخدود حسب الحالة.
- [x] تحسين تباين خامات الجسم والأطراف لتكون الأجزاء مقروءة على خلفيات مختلفة.
- [x] اجتياز بناء Release واختبارات Windows الآلية: 45 اختبارًا ناجحًا، بلا تحذيرات أو أخطاء في سجل البناء للنسخة المؤكدة.
- [x] توليد لقطات WPF لسبع عشرة حالة للشخصية عبر مصفوفة تحجيم الرسم.
- [ ] قبول حي على جهاز Windows فعلي للتحقق من المحاذاة، والضغط والسحب، وحدود النافذة، وتغيّر المقاييس لكل شاشة.

> ملاحظة نطاق: النموذج الحالي مصنوع إجرائيًا من مجسمات WPF ثلاثية الأبعاد وعقد تحويل. ليس نموذجًا فنيًا مستوردًا من Blender/Maya ولا نظام عظام احترافيًا بملفات حركة؛ هذا خارج ما يمكن إثباته من الشيفرة الحالية.

## المرحلة الثانية — الحركة السينمائية والمؤثرات واستجابة المهمة
**الحالة: مكتملة من ناحية التنفيذ والتحقق الآلي. اجتاز Windows CI البناء بلا تحذيرات أو أخطاء، ونجحت الاختبارات 69/69 في [run 39812411884](https://github.com/MohamedElsayedFathy/Layal-Windows-Agent/actions/runs/39812411884). القبول البصري الحي النهائي يظل ضمن المرحلة الثالثة.**

- [x] إضافة تمليس تدريجي لانتقال زوايا الرأس والجسم والمفاصل، بدل تبدل وضع الأطراف دفعة واحدة مع تغير الحالة.
- [x] فصل لغة الحركة السينمائية بحسب الحالة: انجراف القلوب والزهور، دوران رموز البحث/التخطيط والبرمجة، موجات الكلام، ونبضات الانتظار والتحذير.
- [x] ربط الرموز والألوان والتوقيت بحالات المهمة الفعلية: تخطيط، بحث/قراءة، كتابة، كود/أداة، تحقق، انتظار، نجاح وخطأ.
- [x] تحويل الاحتفال إلى دفعة قصيرة متدرجة بتسارع هادئ وتلاشي وجاذبية خفيفة، مع إبقاء الجسيمات ضمن حدود نافذة الشخصية.
- [x] احترام إعداد تعطيل الأنيميشن: تختفي المؤثرات الزخرفية وتتوقف الحركة، بينما تظل مؤشرات الحالة ومرافِقات المهمة متاحة.
- [x] إضافة اختبارات آلية لتصنيف الحالات إلى ملفات الحركة المناسبة؛ اجتازت حزمة الاختبارات كاملة وعددها 69 اختبارًا.

> **حد التحقق:** توليد لقطات WPF ونجاح الاختبارات لا يثبتان وحدهما أن كل حركة تبدو مثالية أثناء الاستخدام الحي. فحص تقاطعات المجسمات، ودقة المحاذاة، والسحب والنقر، والتحجيم الفعلي على شاشات Windows جزء من القبول في المرحلة الثالثة.

## المرحلة الثالثة — المراجعة البصرية الكاملة والثيمات والتحجيم
