# ملاحظات إصدار Layal 0.5.3

## الشات والصوت المحليان افتراضيًا

- أصبح الشات النصي يستخدم نموذج Ollama محليًا افتراضيًا دون الحاجة إلى API key.
- أضيف معالج إعداد بموافقة صريحة قبل تنزيل Ollama ونموذج Qwen3.5 2B وموارد الصوت المحلية.
- أضيف تحويل الكلام إلى نص باستخدام Whisper محليًا، والنطق باستخدام Piper محليًا باللغتين العربية والإنجليزية.
- يتيح زر الصوت المحلي تسجيل دور صوتي، ثم تحويله محليًا وإرسال النص إلى نموذج الشات المحلي لتوليد الرد.
- تظل مهام الوكيل المتقدمة وتحليل الصور والتكاملات والحديث الكامل اللحظي عبر Realtime خيارات سحابية اختيارية.

## الخصوصية والأمان

- يتحقق البرنامج من توقيع مثبّت Ollama قبل تشغيله.
- يتحقق من حجم وبصمة ملف Whisper وملف نموذج Whisper، وبصمة نماذج صوت Piper، ويقيّد استخراج الأرشيف بمسارات آمنة.
- يطلب موافقة الميكروفون قبل التسجيل. يكتب Whisper ملف WAV مؤقتًا محليًا ثم يحاول التطبيق حذفه؛ لا يُرفع الصوت إلى مزود سحابي في الوضع المحلي.
- يدعم الإلغاء أثناء إعداد الموارد، ويعيد استخدام المكونات التي اكتمل تنزيلها.
- أضيفت اختبارات للتحقق من عنوان Ollama المحلي والتحقق من معرّف النموذج وتنظيف النص قبل النطق.

## متطلبات وحدود معلومة

- يحتاج الإعداد الأول إلى الإنترنت، ونحو 4 جيجابايت من التنزيلات وقد يتغير الإجمالي، ومساحة خالية موصى بها لا تقل عن 8 جيجابايت.
- الصوت العربي المضمّن حاليًا صوت Kareem الأردني وليس لهجة مصرية صريحة؛ والإنجليزي Lessac أمريكي.
- الصوت المحلي تبادلي (تسجيل ثم معالجة ثم رد)، وليس full-duplex فوريًا. ميزة المقاطعة أثناء كلام ليال ما زالت متاحة فقط عبر مزود Realtime سحابي اختياري.
- يجب نجاح بناء Windows والاختبارات الآلية على الالتزام النهائي قبل توزيع الحزمة. لم يجرِ اختبار أجهزة ميكروفون/سماعات من جهاز المستخدم نفسه في هذه المرحلة.
