# Layal 0.5.6 — تجديد واجهة الزجاج

## ما الذي تغيّر بصريًا؟

- إضافة طبقات توهّج ضبابية زرقاء وبنفسجية ووردية خلف أسطح التطبيق لإبراز عمق تأثير الزجاج.
- زيادة وضوح الحدود الشفافة والتباين بين الخلفية والأسطح الزجاجية، مع ظلال أعمق لقشرة التنقل ولوحة المحتوى.
- إعادة تنسيق رأس المحادثة وإضافة علامة تعريف صغيرة للمساعد مع الحفاظ على حالة اتصال المزود الحالية.
- إضافة سطح زجاجي مستقل لمنطقة الرسائل، وشريط الحالة، وحاوية إدخال عائمة؛ لا تزال عناصر التحكم نفسها وأسماءها وأحداثها كما هي.
- الإبقاء على الشات بوصفه الشاشة الأولية، وعلى بطاقة الوقت والتاريخ والطقس وتحديثها، وعلى تبويبات التطبيق الأخرى.
- تعطيل التوهجات الزخرفية في وضع تباين Windows العالي احترامًا لإعدادات إمكانية الوصول.

## ما لم يتغيّر؟

لا يغير هذا التحديث منطق إرسال الرسائل أو إدارة المحادثات أو التسجيل الصوتي أو استدعاءات الطقس أو ربط مزود الذكاء الاصطناعي. إنه تحديث بصري للواجهة فقط.

## التحقق والإصدار

يجب نجاح بناء Windows واختبارات WPF المرئية واختبارات لوحة الألوان قبل دمج هذا التحديث. تبقى مراجعة قبول يدوي على Windows ومراجعة التراخيص مطلوبة قبل نشر إصدار نهائي.
