# سجل المتطلبات الرئيسي — Layal / ليال

**الإصدار المرجعي:** 0.5.2  
**الغرض:** سجل متابعة داخلي للمشروع. هذا الملف ليس برومبتًا لمنصة بناء، ولا يساوي تقرير نجاح للتنفيذ.

## قواعد منع نسيان المتطلبات أو إعلان نجاح غير مثبت

1. كل قدرة لها معرّف ثابت `LAYAL-###` في هذا السجل وفي مصفوفة القبول.
2. لا تُحوّل حالة أي مطلب إلى **منفذ ومتحقق** إلا بعد وجود دليل: اختبار آلي ناجح أو اختبار قبول موثق بنتيجته وبيئته.
3. وجود واجهة أو كود أو ملف إعداد لا يثبت أن التكامل يعمل.
4. إذا تعذّر الاختبار بسبب بيئة التشغيل، تبقى الحالة **موجود في المصدر / غير متحقق** أو **محجوب**.
5. عند تغيير متطلب أو إزالته، يجب تسجيل السبب والتأثير بدل حذفه بصمت.
6. قبل كل إصدار: شغّل `tools/validate_project.py`، ثم `VERIFY-LAYAL.ps1` على Windows، واحتفظ بتقرير البناء والاختبارات.
7. لا يُدمج إصدار إلى خط الإصدار المستقر إذا كان البناء فاشلًا أو كانت هناك ثغرة عالية الخطورة بلا معالجة أو استثناء موثق.

## معاني الحالة

- **مصدر موجود — غير متحقق:** توجد شيفرة ذات صلة، لكن لم يُثبت تشغيلها الفعلي.
- **جزئي:** جزء فقط من السلوك المطلوب موجود.
- **غير منفذ:** لا يوجد تنفيذ فعلي للقدرة المذكورة.
- **محجوب:** لا يمكن تأكيده قبل توفير بيئة/جهاز/مفتاح/كاميرا أو أداة مطلوبة.
- **متحقق:** اجتاز معيار القبول المحدد ويوجد دليل قابل للمراجعة.

## بوابات الإصدار

### Gate A — الأساس الأصلي
- [ ] بناء Release ناجح على Windows أو CI Windows.
- [ ] تشغيل التطبيق وإغلاقه دون استثناءات.
- [ ] اختبار النافذة العائمة وTray وحفظ الإعدادات.
- [ ] اختبار حفظ المفاتيح/الذاكرة والتأكد من عدم ظهور الأسرار في السجلات.

### Gate B — الاتصال ومحرك المهام
- [ ] اتصال فعلي بنموذج محدد يدعم tool calling.
- [ ] فشل المفتاح/المزود ينتج حالة صحيحة.
- [ ] الموافقة المرفوضة لا تنفذ العملية.
- [ ] الإلغاء يوقف الطلبات ولا يترك حالة نجاح زائفة.

### Gate C — أدوات الكمبيوتر
- [ ] مساحة عمل محمية واختبارات traversal/reparse points.
- [ ] تحكم Windows فعلي ومحدود الصلاحيات.
- [ ] اختبارات ملفات وبناء واستعادة ناجحة.

### Gate D — صوت/متصفح/كاميرا/MCP
- [ ] لكل تكامل جهاز/حساب/اختبار فعلي متاح.
- [ ] كل مسار بيانات واضح للمستخدم ومصرح به.
- [ ] لا تُعرض المحاكاة كاتصال حقيقي.

### Gate E — التوزيع
- [ ] التثبيت والتحديث والrollback والإزالة مجربة.
- [ ] لا توجد أسرار أو بيانات شخصية في الحزمة.
- [ ] قائمة الاعتماديات والتراخيص مرفقة.

## السجل الحالي

- **الإصدار 0.5.1:** أضاف سجل التتبّع وآلية تحقق قابلة للتكرار.
- **الإصدار 0.5.2:** أضاف مشروع اختبارات C# أوليًا وربط `dotnet test` بـ Windows CI؛ لم يُتحقق من نجاح التنفيذ بعد بسبب غياب .NET SDK في بيئة التأليف.
- فحوص Python الساكنة قابلة للتشغيل في بيئة التطوير هذه.
- لا يوجد .NET SDK في بيئة التطوير الحالية، لذا بناء WPF واختبارات C# لم تُنفّذ هنا. يجب انتظار نتيجة Windows CI قبل تحديث أي حالة إلى متحقق.
- لا يُعد أي متطلب «متحققًا» إلا بعد تشغيل دليل القبول الخاص به.
