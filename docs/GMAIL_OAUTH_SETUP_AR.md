# إعداد Gmail للقراءة فقط في ليال

## ما الذي يفعله التكامل؟

- يستخدم Google OAuth 2.0 لتطبيق Desktop مع PKCE ونافذة موافقة Google الرسمية.
- يطلب النطاق https://www.googleapis.com/auth/gmail.readonly فقط.
- يحفظ Refresh Token في ملف منفصل مشفر باستخدام Windows DPAPI لحساب Windows الحالي.
- يعرض عناوين البريد والنصوص الصريحة المتاحة داخل نافذة محلية؛ حد عرض جسم الرسالة 15,000 حرف.
- لا يرسل أو يحذف أو يعدّل الرسائل، ولا يرسل محتواها إلى نموذج الذكاء الاصطناعي تلقائيًا.
- عند اختيار «إضافة إلى مسودة الشات»، يظهر تأكيد إضافي. يجب على المستخدم مراجعة المسودة والضغط على «إرسال» يدويًا حتى يغادر المحتوى الجهاز نحو مزود AI.

## إعداد Google Cloud مرة واحدة

1. افتح [Google Cloud Console](https://console.cloud.google.com/) واختر مشروعًا أو أنشئ مشروعًا مخصصًا للتطبيق.
2. من **APIs & Services → Library** فعّل **Gmail API**.
3. من **Google Auth Platform** أو **APIs & Services → OAuth consent screen** أكمل اسم التطبيق وبيانات التواصل المطلوبة. اطلب أقل قدر ممكن من البيانات.
4. إذا كان التطبيق في وضع **Testing**، أضف حساب Gmail الذي ستستخدمه ضمن **Test users**.
5. من **APIs & Services → Credentials → Create Credentials → OAuth client ID** اختر نوع التطبيق **Desktop app**.
6. انسخ **Client ID** الذي ينتهي بـ .apps.googleusercontent.com. لا تنسخ Client Secret أو API key؛ ليال لا تطلبهما لهذا التدفق.
7. افتح ليال، اضغط زر **Gmail** في الشات، الصق Client ID واضغط **ربط Gmail**، ثم أكمل صفحة Google الرسمية بنفس الحساب المطلوب.
8. بعد العودة إلى ليال اضغط **تحديث**، واختر رسالة لمعاينة النص محليًا.

قد يتطلب تطبيق OAuth غير المنشور اختبار الحساب أو إعداد صفحة الموافقة حسب سياسات Google ونوع المشروع. لا تضع بيانات اعتمادك في المحادثة أو في مستودع Git.

## التخزين والفصل وإلغاء الوصول

- يُخزن Client ID العام في إعدادات ليال المحلية؛ لا يُعد سرًا.
- يُخزن Refresh Token في المسار %LOCALAPPDATA%/Layal/secrets/gmail-refresh-token.dpapi مشفرًا عبر DPAPI للمستخدم الحالي.
- زر **فصل محليًا** يحذف الرمز من الجهاز فقط. لإلغاء تفويض Google بالكامل، افتح إعدادات أمان حساب Google وأزل وصول التطبيق أيضًا.
- يظل النطاق للقراءة فقط؛ واجهة ليال لا تحتوي على إرسال أو حذف أو تعديل للبريد.
- لا يتم تنفيذ أي مهمة AI أو إرسال بريد تلقائيًا عند فتح الرسالة. مشاركة النص مع نموذج AI تتطلب إضافته إلى مسودة الشات ثم الضغط على إرسال.

## حدود الإصدار الحالي

لا يُعرض محتوى HTML فقط أو المرفقات؛ تتم معاينة نص text/plain فقط. لا توجد مزامنة خلفية ولا فحص مستمر للبريد ولا إرسال أو إنشاء مسودات Gmail عبر API. الاختبار العملي لتسجيل الدخول يتطلب Client ID صالحًا وحساب Google يسمح بالموافقة، إلى جانب نجاح CI على Windows.
