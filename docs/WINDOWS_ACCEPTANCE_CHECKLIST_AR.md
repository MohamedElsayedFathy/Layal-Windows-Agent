# قائمة قبول Windows اليدوي لوظائف Layal

**الغرض:** توثيق اختبارات لا يمكن اعتبارها ناجحة بمجرد بناء المشروع أو تشغيل اختبارات الوحدة. يجب تنفيذها على جهاز Windows فعلي، وتسجيل النتيجة والدليل. هذه القائمة لا تعلن نجاح أي اختبار لم يُنفذ.

لكل حالة سجّل PASS أو FAIL أو BLOCKED أو NOT RUN، والتاريخ وGit SHA وخطوات إعادة الإنتاج والدليل. استخدم عينات اصطناعية فقط، ولا ترفق ملفات أو تسجيلات تحتوي بيانات حقيقية.

## AYO-01 — الصوت والتحدث
- [ ] ابدأ التسجيل وأوقفه؛ تحقق من WAV صالح وحد 120 ثانية.
- [ ] اختبر عينات منفصلة: عامية مصرية، فصحى، إنجليزية، ومزيج عربي/إنجليزي، وقارن النص بمرجع.
- [ ] اختبر رفض إذن الميكروفون، فصل الجهاز، تغيير جهاز الإدخال، وإعادة توصيله.
- [ ] ألغِ التسجيل أثناء الالتقاط وأثناء إنهاء التسجيل؛ لا تُرسل الموجة الملغاة إلى STT.
- [ ] اختبر الكتم والمقاطعة والاستئناف وTTS/Piper/Realtime المتاح، ثم أعد تشغيل التطبيق وتحقق من تحرير الجهاز.

## AYO-02/03 — Quick Ask والاختصارات
- [ ] جرّب كل اختصار في ثلاثة تطبيقات خارج Layal، وفي ملء الشاشة.
- [ ] اختبر تعارض الاختصارات وتغيير الاختصار أثناء التشغيل وإلغاء التسجيل السابق.
- [ ] افتح Quick Ask مع وجود مسودة في الشات؛ تحقق من عدم فقدها.
- [ ] اختبر إغلاق Quick Ask أثناء طلب جارٍ، وفشل المزود، وانقطاع الشبكة.

## AYO-04/12 — الإلغاء والمهام متعددة الخطوات
- [ ] اضغط Esc أثناء موافقة إنشاء ملف؛ يجب ألا يُنشأ.
- [ ] ألغِ مهمة متعددة الأدوات بين خطوتين؛ يجب ألا تبدأ أداة لاحقة.
- [ ] اختبر timeout أو انقطاع Edge/الشبكة في أداة خارجية.
- [ ] أنشئ ملفًا ثم عدّله؛ تحقق من بقاء النسخة الاحتياطية ووجود مرجع artifact واحد.
- [ ] اختبر إلغاء التنزيل والصوت وقراءة الملفات وبناء/اختبار مشروع موثوق، بما يشمل العمليات الفرعية.

## AYO-05/06 — التقاط الشاشة والقص
- [ ] اختبر شاشة واحدة ثم شاشتين بدقتين ومقياسي DPI مختلفين (100%/125%/150%/200%).
- [ ] التقط الشاشة التي عليها المؤشر وتأكد أن نافذة Layal لا تظهر.
- [ ] جرّب القص بالماوس ولوحة المفاتيح: تحديد وتحريك وتغيير الحجم وتأكيد وإلغاء.
- [ ] افصل شاشة أو غيّر DPI أثناء فتح نافذة القص؛ تحقق من صحة الإحداثيات.
- [ ] تحقق من بقاء المعاينة محلية حتى Send، ومن تسميات قارئ الشاشة والتركيز المرئي.

## AYO-07/16 — UI Automation والموافقات
- [ ] جرّب تطبيقات Win32 وWPF وWinUI ونافذة متصفح خارجية.
- [ ] ارفض الموافقة؛ يجب ألا تحدث قراءة أو عملية.
- [ ] غيّر النافذة أو عنصر التحكم بعد عرض الموافقة؛ يجب رفض الفعل عند تغير HWND/PID/AutomationId.
- [ ] اختبر عنصرًا مخفيًا أو معطلًا أو غامضًا أو محميًا.
- [ ] تحقق من أن فحص العناصر لا يقرأ قيم الحقول القابلة للتحرير.
- [ ] راجع جميع الأدوات يدويًا: البيانات المقروءة، البيانات المرسلة، والأثر الممكن بعد الموافقة.

## AYO-08/09 — OCR ومستندات PDF/Office
- [ ] استخدم عينات عربية وإنجليزية ومختلطة: صور واضحة ومائلة ومنخفضة الجودة، PDF ممسوح ومتعدد الصفحات.
- [ ] اختبر حزم OCR العربية فقط والإنجليزية فقط وكليهما وغياب الحزم.
- [ ] قارن الأسماء والأرقام والتواريخ والنص من اليمين لليسار مع مرجع دقيق.
- [ ] اختبر CSV/XLSX متعدد الأوراق والجداول الكبيرة وحدود الصفوف والخلايا.
- [ ] اختبر ملفًا تالفًا ومشفّرًا ومحميًا وOffice يتضمن ماكرو وملفًا كبيرًا؛ يجب رفض غير المدعوم.
- [ ] تحقق من أن الاستخراج محلي، ولا يُرسل النص إلا بعد المعاينة والإرفاق والإرسال الصريح.

## AYO-10/11 — البحث المباشر والتحقق
- [ ] اختبر بحثًا بمصادر أولية حديثة وآخر لا يوفر مصادر مناسبة.
- [ ] تحقق من عدم الخلط بين تاريخ النشر وتاريخ الحدث.
- [ ] اختبر صفحات محظورة/تحدي/تسجيل دخول/إعادة توجيه/مصدر غير متاح.
- [ ] ارفض أحد استعلامات fact-check أو مصدرًا؛ يجب ألا يُنفذ الجزء المرفوض.
- [ ] تحقق من معاملة محتوى الصفحة كبيانات غير موثوقة وعدم تنفيذ تعليماته.

## AYO-13/20 — مساحة العمل ومراجع الملفات والنسخ
- [ ] اختبر مجلدًا وملفًا عاديًا ورابطًا رمزيًا وjunction إلى خارج LayalWorkspace.
- [ ] احذف artifact بعد الموافقة؛ تحقق من نقله إلى Recycle Bin وإزالة المرجع من سجل المهمة.
- [ ] غيّر الملف أو مساره بين العرض والتأكيد؛ يجب رفض المسار المتغير.
- [ ] صدّر JSON وافحص أنه غير مشفر ويحتوي المهام والملاحظات المؤرشفة وmanifest metadata فقط، لا محتوى الملفات.
- [ ] استورد إلى مخزن فارغ ثم كرر الاستيراد؛ يجب ألا تتكرر السجلات.
- [ ] استورد معرّفًا موجودًا بمحتوى مختلف؛ يجب أن يبقى السجل المحلي كما هو.
- [ ] اختبر إصدارًا غير مدعوم ونسخة كبيرة ومسار manifest غير صالح ومحتوى يشبه الأسرار؛ يجب رفض النسخة قبل التعديل.
- [ ] اختبر توقف التطبيق أثناء الاستيراد وافحص مخزني DPAPI بعد إعادة التشغيل.
- [ ] تذكّر أن manifest لا ينسخ ملفات المشروع ولا يستعيدها.

## AYO-15 — متصفح Edge والتنزيل والرفع
استخدم موقع اختبار تملكه وملفات اصطناعية فقط.
- [ ] ارفض موافقات التنقل/القراءة/النقر/التعبئة/التنزيل؛ يجب ألا يبدأ الأثر.
- [ ] غيّر URL أو التبويب أو العنصر أثناء انتظار الموافقة؛ يجب رفض الفعل.
- [ ] اختبر تنزيلًا مسموحًا وتحويلًا لنطاق آخر وعنوان IP خاصًا وملفًا كبيرًا وتوقيعًا غير مطابق.
- [ ] جرّب browser_upload_file بملف PDF/TXT/صورة اصطناعية إلى وجهة اختبار موثوقة.
- [ ] تحقق أن الموافقة تظهر الموقع والصفحة والمحدد والمسار المحلي والاسم والنوع والحجم، وتحذر من الرفع الفوري عند اختيار الملف.
- [ ] غيّر محتوى الملف بعد المعاينة وقبل التأكيد؛ يجب أن تمنع بصمة SHA-256 الرفع.
- [ ] اختبر ملفًا خارج مساحة العمل ورابطًا رمزيًا وملفًا تنفيذيًا وفارغًا وأكبر من 20 MiB؛ يجب رفضها.
- [ ] اختبر حقل input[type=file] ظاهرًا وآخر مخفيًا؛ المخفي غير مدعوم عمدًا.
- [ ] تحقق أن Layal لا يضغط Submit ولا ينقل Cookies من المتصفح الشخصي. قد يبدأ الموقع الرفع تلقائيًا عند اختيار الملف؛ لذا يجب الموافقة صراحةً على الموقع نفسه.

## AYO-17/18/19 — الذاكرة وخريطة Lore Web
- [ ] أنشئ ملاحظة وصنّفها وابحث وعدّل وأرشف واستعد واحذف بموافقة.
- [ ] أعد تشغيل Layal وتحقق من بقاء DPAPI؛ اختبر مستخدم Windows آخر.
- [ ] اختبر 100 ملاحظة بالعربية والإنجليزية في الخريطة، من حيث الأداء وقارئ الشاشة.
- [ ] تحقق أن روابط الخريطة ناتجة عن التصنيف/تشابه العنوان/الزمن وليست علاقات دلالية مضمونة.
- [ ] اختبر تصدير JSON غير المشفر وتحذير الخصوصية.

## AYO-21/23/24 — التذكيرات والإشعارات
- [ ] اختبر تذكيرًا لمرة واحدة ويوميًا وأسبوعيًا، وتعديل الموعد وحذفه ومنع التكرار.
- [ ] اختبر نوم Windows واستئنافه وإعادة التشغيل والمنطقة الزمنية والتوقيت الصيفي/الشتوي.
- [ ] اختبر درع الخصوصية ووضع الألعاب وإخفاء/إغلاق Layal.
- [ ] انقر الإشعار السياقي؛ يجب فتح المهمة المقصودة دون تشغيلها أو تعديلها.
- [ ] تحقق من انتهاء الإجراء أحادي الاستخدام بعد المهلة.
- [ ] لا تفترض أن التذكيرات تعمل بعد إنهاء Layal؛ لا يوجد Task Scheduler للتسليم بعد الإغلاق حتى يُنفذ ويُختبر منفصلًا.

## AYO-25/26 — Gmail والطقس والموقع
- [ ] اختبر Google OAuth على حساب اختبار مخصص وراجع Gmail readonly scope.
- [ ] اختبر رسالة text/plain وHTML وmultipart ومرفقات UTF-8 صالحة/معطوبة وكبيرة.
- [ ] تحقق من عدم حفظ/تنفيذ المرفقات الثنائية أو غير المدعومة، وعدم إرسال المعاينة تلقائيًا للمزود.
- [ ] اختبر رفض إذن الموقع والمدينة اليدوية وانقطاع الشبكة وعدم حفظ الإحداثيات دون حاجة.
- [ ] تحقق من أن Gmail لا يرسل أو يحذف أو يعدّل الرسائل.

## AYO-27/28/29/30 — الألعاب والنبرات والثيمات والأداء
- [ ] اختبر HUD يدويًا مع لعبة ملء الشاشة، وفقدان/استعادة التركيز.
- [ ] تحقق من عدم قراءة عمليات الألعاب أو حقن إدخال فيها.
- [ ] اختبر النبرات بالعربية والإنجليزية وطلبات حساسة؛ يجب ألا تتغير الأمان أو صلاحيات الأدوات.
- [ ] افحص الثيمات الفاتحة/الداكنة والتركيز والتحويم والتعطيل في كل تبويب ومع DPI مختلف.
- [ ] اختبر Windows High Contrast؛ يجب أن يتقدم على ثيم Layal.
- [ ] قِس CPU/RAM/GC على جهاز ضعيف ومتوسط قبل وضع الأداء وبعده تحت حمل متساوٍ.
- [ ] أوقف وضع الأداء وتحقق من عودة GLB والمؤثرات دون تسرب مؤقتات.

## AYO-31/32/33 — الحافظة وIncognito ودرع الخصوصية
- [ ] اختبر قراءة النص والصورة من تطبيقات مختلفة وقفل الحافظة وحدود الحجم.
- [ ] تحقق من وجود معاينة محلية وعدم الإرسال قبل Send.
- [ ] في Incognito، اختبر الشات وQuick Ask واللغة والثيم وإغلاق التطبيق وإعادة تشغيله.
- [ ] تحقق من عدم حفظ رسائل الشات والمرفقات المؤقتة، مع الإقرار أن المزود قد يحتفظ بما أُرسل إليه وأن سجل المهام والذاكرة خارج Incognito.
- [ ] فعّل درع الخصوصية أثناء التسجيل والكاميرا والقص وقراءة الحافظة ومهمة وكيل؛ يجب إلغاء العمليات ومنع الفحص اللاحق.
- [ ] تحقق من تحرير موارد الميكروفون والكاميرا فعليًا.
- [ ] تحقق من إزالة مراجع الالتقاط المعلقة دون حذف ملفات المستخدم المختارة.
