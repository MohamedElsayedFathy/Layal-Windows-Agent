# قبول Windows الحي على حساب المستخدم الحالي مع عزل بيانات الاختبار

يتيح هذا الوضع تشغيل اختبارات الواجهة المحمولة على جلسة Windows التفاعلية الحالية دون استخدام بيانات Layal الشخصية الموجودة في ملف المستخدم.

## نطاق العزل

عند تشغيل `tools/Start-LayalLiveAcceptance.ps1` مع `-ConfirmIsolatedCurrentUserProfile` ينشئ المشغّل مجلد جلسة جديدًا داخل مجلد الأدلة، ويضبط متغير العملية `LAYAL_ACCEPTANCE_ROOT` للعمليات الفرعية فقط.

يستخدم التطبيق داخله:

- `LocalAppData/Layal` للإعدادات والسجلات والبيانات المحلية وملفات DPAPI الجديدة.
- `Documents/LayalWorkspace` لمساحة عمل الاختبار.
- أسماء Mutex وEvent مستقلة حتى لا تتداخل جلسة الاختبار مع مثيل Layal العادي.
- لا ينشئ ولا يحدّث ولا يحذف مهمة تذكيرات Windows Task Scheduler أثناء هذا الوضع.

يبقى مجلد المستخدم الحقيقي `%LOCALAPPDATA%\Layal` ومساحة العمل الحقيقية `%USERPROFILE%\Documents\LayalWorkspace` خارج نطاق الاختبار ولا يقرأهما التطبيق في هذا الوضع. لا تحذفهما ولا تنقلهما.

## حدود مهمة

- أغلق أي عملية Layal قبل بدء الاختبار؛ المشغّل يرفض المتابعة إذا وجد عملية قائمة.
- الاختبار يحرك نافذة Layal والمؤشر والماوس؛ لا تستخدم سطح المكتب أثناء القياسات.
- لا تستخدم مفاتيح API أو حسابات مزود حقيقية أو رسائل شخصية. استخدم بيانات تركيبية فقط.
- هذا الوضع مخصص لاختبار الحزمة المحمولة. لا تختبر المثبّت أو الترقية أو rollback أو uninstall على ملفك الشخصي.
- يظل فحص Narrator/NVDA وHigh Contrast والمراجعة البصرية RTL/LTR وعبور الشاشات باختلاف DPI مراجعة بشرية منفصلة.
- وجود `PASS` في التشخيصات الآلية لا يحوّل قرار القبول إلى GO؛ تبقى بوابات المراجعة اليدوية والإصدار الأخرى مطلوبة.
