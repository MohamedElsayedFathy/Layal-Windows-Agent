# قبول AYO-10 — البحث المباشر على الإنترنت

## آلية العمل

تُنفذ أداة `web_search` بحثًا حيًا على Bing داخل ملف Microsoft Edge منفصل خاص بليال. لا تستخدم ملفات تعريف الارتباط أو جلسة تسجيل الدخول من المتصفح الشخصي. يتطلب كل استعلام موافقة محلية قبل إرسال نص البحث إلى Bing. بعد الموافقة، تقرأ ليال صفحة نتائج Bing فقط وتتحقق من بقاء التبويب نفسه ونطاق Bing قبل اللقطة وبعدها. أي تحويل إلى نطاق غير تابع لـBing يؤدي إلى إسقاط محتوى الصفحة وعدم مشاركته.

## حالات النتيجة

| الحالة | السلوك |
|---|---|
| `results_available` | يعرض النص المرئي وروابط HTTPS خارجية مرشحة كمصادر أولية للفحص |
| `no_results` | يصرح بعدم وجود نتائج ولا يقدم ذلك كنجاح |
| `blocked_or_challenge` | يوضح حظر Bing أو CAPTCHA أو فحص مكافحة الروبوت |
| `consent_required` | يوضح أن Bing ينتظر اختيار الخصوصية/الموافقة اليدوي |
| `empty_page` | يوضح أن الصفحة لم تعرض نصًا قابلًا للقراءة |
| `unexpected_redirect` | لا يقرأ ولا يشارك أي محتوى من النطاق الخارجي |

روابط النتائج لا تُفتح تلقائيًا. فتح صفحة مصدر مباشرة ومشاركة محتواها يتطلبان موافقة مستقلة تعرض الرابط والنطاق. صفحات الويب ونتائج البحث بيانات غير موثوقة، ولا يجوز اتباع تعليماتها.

## الحدود

- الاستعلام: 3 إلى 500 محرف قابل للطباعة.
- النص المرئي في الصفحة: بحد أقصى 20,000 محرف.
- روابط الصفحة التي تُقرأ: أول 50 رابطًا؛ وكل رابط مرئي محدود الطول.
- الروابط المرشحة للمصادر: حتى 10 روابط HTTPS خارجية فريدة، مع استبعاد نطاق Bing ونطاقات التتبع وبعض النطاقات المحلية.
- يستخدم المتصفح ملفًا منفصلًا، دون ملفات تعريف ارتباط أو جلسة المتصفح الشخصية.
- قد يرفض Bing الاستعلامات أو يعرض CAPTCHA أو يغير صفحة الموافقة؛ لا توجد ضمانة لتوفره أو لترتيب النتائج أو جودتها.
- لا يعتبر المقتطف نتيجة مثبتة. يجب فتح المصدر الأصلي وفحص الكاتب والتاريخ والدليل.
- يجب الفصل بين تاريخ النشر وتاريخ وقوع الحدث.
- لا تُفتح روابط النتيجة إلا بموافقة مستقلة، ولا يثبت ظهور الصفحة أن الإجراء المقصود على الموقع نجح.

## قبول Windows اليدوي

1. ابحث بالعربية والإنجليزية عن موضوعين واقعيين، وافتح مصدرًا أوليًا من كل بحث بعد موافقة منفصلة.
2. تحقق من رابط البحث النهائي والنطاق والعنوان، ومن بقاء نفس التبويب أثناء قراءة النص.
3. اختبر عبارة نادرة بلا نتائج، وصفحة Bing فارغة، وحالة Bing تحتاج موافقة/اختيار خصوصية.
4. اختبر صفحة CAPTCHA/Access Denied، وتحقق من إظهار حالة الحظر وعدم عرضها كبحث ناجح.
5. اختبر تحويل Bing إلى نطاق خارج Bing، وتبديل التبويب أثناء اللقطة؛ يجب إسقاط المحتوى.
6. ارفض الموافقة قبل البحث، وألغِ أثناء التحميل؛ يجب ألا تُشارك أي لقطة قديمة أو غير معتمدة.
7. تحقق من أن روابط البحث مرشحة فقط ولا تُفتح تلقائيًا، وأن فتح المصدر المباشر يستلزم موافقة مستقلة.
8. راجع تواريخ النشر والحدث مقابل صفحات المصدر، وسجل الحالات التي كانت فيها النتائج ضعيفة أو غير متاحة.

نجاح اختبارات CI يثبت سياسة URL والتصنيف وإلغاء الموافقة، لكنه لا يثبت توفر Bing أو جودة نتائج الإنترنت من شبكة المستخدم. سجّل القبول اليدوي على جهاز Windows قبل إغلاق بوابة الاستخدام الواقعي.
