# خريطة التطوير الرئيسية لمشروع Layal — نسخة الحالة المحدثة

**تاريخ التحديث:** 13 نوفمبر 2026  
**المستودع:** `MohamedElsayedFathy/Layal-Windows-Agent`  
**الفرع الذي تم تحديثه:** `main` — دون إنشاء فرع جديد  
**خط الأساس:** `4df2a067c4c6df161d140e2f06d252745c1f8d3b`  
**الإصدار الموصوف في المصدر:** `0.5.8`  
**الحالة العامة:** تطوير داخلي؛ قرار التوزيع العام ما زال **NO-GO** حتى إغلاق بوابات القبول اليدوي والتوقيع والحقوق والتراخيص.

> هذه هي نسخة التنفيذ الحية التي تحدّث حالة العمل. النسخة الأصلية الكاملة من خريطة العمل محفوظة دون تعديل في `docs/reference/Layal_Master_Development_Roadmap_AR_Original.docx`، ومعها تصدير Markdown كامل في `docs/reference/LAYAL_MASTER_DEVELOPMENT_ROADMAP_AR_ARCHIVE.md`. الأرشيف مرجع تاريخي، ولا يُستبدل بهذه النسخة.

## 1. ملخص الحالة الحالية

وصل `main` إلى commit `4df2a067c4c6df161d140e2f06d252745c1f8d3b` بعد دمج PR #166. المشروع يحتوي الآن على نواة محلية رمزية محدودة، وإدارة ذاكرة وملفات، ومجموعة أدوات للمتصفح وWindows وواجهات API، وخدمات صوت وكاميرات ومستندات. لكن وجود الأداة في المصدر لا يعني بالضرورة أن النواة المحلية النشطة تستطيع استدعاءها؛ كما أن نجاح CI لا يساوي قبولًا يدويًا على جهاز Windows حقيقي.

أهم نتيجة تنظيمية: اكتملت حزمة استخراج مسؤوليات تنفيذ الأدوات من `AgentToolExecutor` عبر PRs #162 إلى #166. والخطوة المعمارية التالية هي تفكيك `BrowserAutomationService`، بدءًا بخدمة قراءة الصفحات، ثم فصل أفعال المتصفح وإدارة جلسة Edge.

**نتيجة آخر بوابة CI مرتبطة مباشرةً بالتغيير الأخير:** نجحت الفحوص الأربعة على رأس PR #166 `dea41bcff73898bce28e2d0d6ba26100ec725d6a`: Windows build، وFull Windows acceptance الآلي، وتدقيق NuGet والتراخيص، وفحص الأسرار. دُمج PR #166 في `main` بطريقة Squash. هذا لا يغلق اختبارات سطح المكتب الفعلية أو الأجهزة الحقيقية.

| ربط كل الأدوات بالنواة المحلية | **جزئي** | توصيل المتصفح المتقدم وWindows UI Automation وREST APIs وGmail والتذكيرات وغيرها بمسار تنفيذ موحد، مع الحفاظ على PermissionBroker والتحقق من الهدف والنتيجة. |
| تحكم عام بالماوس والكيبورد والإحداثيات | **غير منفذ** | طبقة تحكم محدودة الصلاحيات، موافقة قبل الأفعال، منع النقرات الحساسة، وربط الفعل بهدف واضح والتحقق من الحالة النهائية. |
| فهم الشاشة والصور والرؤية الحاسوبية | **غير منفذ في مسار النواة** | محرك رؤية محلي مستقل لتحليل صورة ثابتة/لقطة مع سياسة خصوصية واختبارات ذاكرة وأداء. المعاينة الحالية لا تعني الفهم. |
| فهم الفيديو المباشر وتتبع الأجسام | **غير منفذ** | تحليل إطارات مضبوط، تتبع، تسجيل وتنبيهات واحتفاظ بالأحداث وقياس موارد؛ لا يوجد تنفيذ كامل حاليًا. |
| ذاكرة دلالية وRAG | **غير منفذ** | فهرسة واسترجاع دلالي، مصادر وإسناد، تحديث/حذف آمن، وتقييم الاسترجاع. |
| ترحيل الذاكرة إلى SQLite | **غير منفذ** | مخطط ترحيل وإصدارات ونسخ احتياطية واختبارات رجوع مع الحفاظ على بيانات المستخدم الحالية. |
| تدريب ذاتي/إحصائي وإدارة نموذج | **غير منفذ** | مجموعة بيانات يوافق عليها المستخدم، تقييم، إصدارات نموذج، rollback، وإثبات عدم استخدام بيانات خاصة دون تصريح. الاختصارات وسجل الخبرات لا يحققان ذلك. |
| تشغيل سكربتات المهارات | **غير منفذ** | Sandbox حقيقي بعزل ملفات/شبكة/عمليات وحدود وقت وموارد واختبارات escape. لا يُفعّل التشغيل قبل إثبات حد العزل. |
| بروتوكول MCP | **غير منفذ** | إعداد عميل MCP، اكتشاف الأدوات وschemas، موافقات، مهلات وسجلات وتحقق من مصادر الخوادم. |
| متصفح متقدم | **جزئي** | دعم تبويبات/إطارات معقدة وسجل provenance أوسع وعرض بحث موثق بمصادر، مع بقاء موافقات الأفعال والتحميل والرفع والتحقق من النتائج. تنزيل ورفع الملفات موجودان بالفعل في طبقة الأدوات. |
