# سجل تنفيذ خريطة التطوير الرئيسية

هذا السجل يربط الخريطة الرئيسية التي زود بها المستخدم بحالة مستودع Layal الحالية. تعليمات الخريطة تصف الهدف المطلوب، لكنها لا تثبت أن ميزة ما موجودة أو مجتازة للاختبار. نفّذ حزمة واحدة في كل مرة، وحدّث الحالة بدليل من المصدر أو CI أو القبول العملي.

## خط الأساس

- المستودع: `MohamedElsayedFathy/Layal-Windows-Agent`.
- الفرع: `main`.
- Commit `main` الحالي بعد PR #156 و#157: `364da3c8ba9e02e25120c45f4a5cf4e42fb757c3` (12 نوفمبر 2026).
- دمج PR #156 حدّث سجل الخريطة وخط الأساس؛ ودمج PR #157 أضاف وسيط صلاحيات الأدوات وسجل التدقيق.
- رأس المصدر المختبر في PR #157: `c30892ee93ec039cbf4819a908d00c44a2a386ec`. اجتاز Windows Release والاختبارات الآلية وقبول Windows ودورة المثبّت والتوزيع، إضافة إلى فحوص NuGet والأمان وسلسلة التوريد. هذا دليل CI، وليس قبولًا يدويًا للشاشة أو الجهاز.
- النسخة الموصوفة في README هي 0.5.8. نجاح CI لا يثبت قبول قارئات الشاشة أو الأجهزة الفعلية ولا جاهزية التوزيع العام.

## شروط قبل الانتقال

1. أغلق القبول العملي UI-00 على جهاز Windows وسجل commit والبيئة والنتائج.
2. لا تعد تطبيق تغييرات الواجهة الموجودة في `main`؛ ابدأ من فجوة مثبتة بالاختبار أو المراجعة.
3. قبل Phase 2، احسم التعارض المعماري: الخريطة الجديدة تجعل النموذج المحلي عقل ليال، بينما 0.5.8 على `main` يستخدم نواة رمزية حتمية ولا يستدعي نموذج محادثة محليًا أو سحابيًا. كلا الوصفين يجب أن يظلا منفصلين حتى تنفيذ التغيير واختباره.
4. استخدم فرعًا مستقلًا وPR لكل حزمة، واترك الدمج في `main` لموافقة المستخدم الصريحة.

## الحزمة التالية

**إكمال قبول UI-00 العملي ثم إصلاح الفشل الصغير وإعادة اختباره** قبل بدء حزمة برمجية أخرى. استُخدم artifact CI بعد مطابقة SHA-256. نجحت ملاحظات العتامة، تغيير اللغة والثيم، التنقل، السحب، وتغيير الحجم. عند 922×602 ظل موضع نافذة الشخصية المحفوظ مستقلًا عن نافذة Layal وحجب عنوان الصفحة وزر سجل المحادثات عبر كل تركيبات اللغة والثيم المختبرة؛ لا يثبت ذلك أن الموضع نفسه سيُختار في ملف مستخدم جديد. النموذج وسجل النتائج في [سجل قبول UI-00](UI_00_WINDOWS_ACCEPTANCE_AR.md). لم تتوفر مساحة لارتفاع 900px، ولم يُختبر DPI أو تعدد الشاشات؛ تبقى هذه العناصر Pending. لا تُعلن الحزمة مقبولة قبل معالجة/حسم التداخل وإعادة الاختبار، مع حفظ دليل لا يكشف بيانات المحادثات المحلية.
