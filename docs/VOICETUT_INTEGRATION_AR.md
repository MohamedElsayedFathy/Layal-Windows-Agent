# تكامل VoiceTut-TTS في ليال

**المحرك:** `mohammedaly22/VoiceTut-TTS` بالإصدار المثبت `b36bdf4416864d84f47ca77ce3decf34f6ab16cc`، مع OmniVoice commit `08be0b4ccbac3e13e374e86fbfead4b4cac343e2` وVoiceTut source commit `44cba00cd3ddb04b5213353e19e960045e332da7`.

## وضع الصوت والهوية

- Voice Design فقط بوصف الهوية الافتراضي `female, child, very high pitch`.
- نمط الإلقاء الافتراضي في Layal هو `playful`.
- لا تُحمّل ملفات reference speakers، ولا يعرض تكامل Layal أصوات النموذج المرجعية المضمّنة، ولا يقبل مرجعًا صوتيًا أو مسار voice cloning.
- ترخيص VoiceTut وOmniVoice Apache-2.0 كما هو مثبت في ملفات التراخيص بالمستودع. هذا الترخيص لا يثبت وحده حقوق هوية الصوت الناتج أو القبول السمعي؛ حالات الحقوق والاعتماد تظل pending حتى مراجعة مستقلة.

## مسار توليد الكلام

1. يمر نص الرد إلى `LocalSpeechLanguageProvider`.
2. يصنف `SpeechLanguageEngine` النص إلى مصرية أو فصحى أو إنجليزية أو مختلط/غير محدد.
3. يختار التطبيق رمز VoiceTut: المصرية `arz`، الفصحى `ar`، الإنجليزية `en`. في المختلط، يُختار `ar` فقط إذا كانت جميع المقاطع العربية مصنفة فصحى؛ أي مقطع مصري أو غير محدد يختار `arz`.
4. يضيف `VoiceDeliveryStylePolicy` توجيه النمط الحالي إلى وصف الهوية نفسه، ثم يطبق معامل سرعة محافظًا. النمط لا ينشئ صوتًا ثانيًا ولا يغيّر هوية ليال.
5. يتصل عميل Windows بخادم VoiceTut على `127.0.0.1` فقط، بمنفذ عشوائي ورمز جلسة في `X-Layal-Token`. تُبث مقاطع PCM16 عبر NDJSON ويبدأ NAudio التشغيل أثناء وصول المقاطع.

**حد الفصحى:** واجهة الجسر تقبل `ar`، وأصبح التطبيق يرسل هذا الرمز عند تصنيف النص فصحى، لكن VoiceTut لا يملك في هذا المشروع قبولًا سمعيًا نهائيًا للفصحى. لذلك تظل الفصحى مسارًا استكشافيًا ولا تدخل في قائمة `supportedLanguages` المعلنة حتى مراجعتها.

## الأنماط

الأنماط المدعومة في إعدادات Layal: `playful`, `natural`, `gentle`, `bright`, `clear`, `empathetic`, `serious`, `energetic`. الافتراضي `playful`.

يوضع توجيه إنجليزي قصير للنمط بعد وصف الهوية، مع ضبط سرعة منفصل. الحد الأقصى لتعليمة VoiceTut المركبة 500 حرف؛ حقل هوية Voice Design الأساسي في إعدادات المستخدم محدود بـ300 حرف. الضبط لا يضمن تحقيق المشاعر كاملة أو تغيير خامة الصوت.

## موارد Windows وسلامة النموذج

- Windows x64.
- Python x64 متوافق؛ يستخدم التكامل البيئة المعزولة الخاصة ببيانات Layal.
- PyTorch/TorchAudio 2.8.0، OmniVoice وVoiceTut من commits مثبتة.
- أوزان VoiceTut تقارب 2.45 GB بالإضافة إلى tokenizer والاعتماديات.
- يتحقق الجسر من حجم وبصمة SHA-256 لـ `model.safetensors` و`tokenizer.json` قبل تحميل النموذج.
- يستبعد `reference_speakers` من `snapshot_download` ويعيّن مسارًا غير موجود لتعطيل registry.
- عنوان الاستماع loopback فقط، ولا تقبل الواجهة عنوان مضيف بعيد.

## واجهات الجسر

| المسار | الوظيفة |
|---|---|
| `/healthz` | الجاهزية وسلامة الأوزان ومعلومات الجهاز |
| `/v1/info` | معلومات النموذج ووضع Voice Design |
| `/v1/metrics` | آخر القياسات |
| `/v1/normalize` | تطبيع النص المحلي |
| `/v1/stream` | توليد صوت PCM16 متدفق |
| `/v1/synthesize` | توليد صوت عبر واجهة التوليد |

كل المسارات تتطلب رمز الجلسة. حجم النص محدود بـ6000 حرف، وتعليمة الصوت المركبة بـ500 حرف. الرموز المسموحة للغة هي `arz`, `ar`, `en`.

## التقييم

مولّد `tools/evaluation/render_voicetut_evaluation.py` يستخدم نفس مجموعة الـ18 عبارة ويخرج جميع الأنماط الثمانية: 112 عينة ضمن اللغات الثلاث المعلنة، و32 عينة فصحى استكشافية. يُسجل WAV PCM16 وSHA-256، ومدة الصوت، ووقت التوليد، وTTFA وRTF.

لا تُعد نتائج التوليد أو قياسات الإشارة إثباتًا لجمال الصوت. يلزم مراجعان مستقلان لكل عينة، ومراجعة ملاءمة الهوية والحقوق، واعتماد يدوي. تظل هذه الحالات pending حتى تنفيذ الاستماع الفعلي على Windows.
