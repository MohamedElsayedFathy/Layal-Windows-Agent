# AYO-28 — قبول الشخصيات وأنماط الرد والنبرات الصوتية

## النطاق المنفذ

- عرض شخصية ليال وحدها، أو الروبوت وحده، أو الاثنين معًا؛ الإعداد محفوظ محليًا ويُطبّق فورًا على نافذة الماسكوت.
- اسم ووصف UI Automation يتبعان العنصر المرئي والحالة الحالية. وضعا الشخصية لا يغيران هوية المساعد أو صلاحياته.
- أسلوب صياغة النص (دافئ/مركز/احترافي) مستقل عن هوية الصوت ونبرة الإلقاء.
- أصوات Realtime المدمجة القابلة للاختيار: Marin وCedar وAlloy وAsh وBallad وCoral وEcho وSage وShimmer وVerse.
- نبرة الإلقاء: طبيعية/هادئة/مشرقة/واضحة. تصل إلى Realtime TTS وردود المحادثة الصوتية المباشرة.
- Piper المحلي يطبق `length_scale` فقط: الطبيعي 1.00، الهادئ 1.10، المشرق 0.94، الواضح 1.03. لا يدعم التنفيذ المحلي الحالي تغيير timbre أو الانفعال؛ هوية الصوت المحلية العربية/الإنجليزية لا تتغير.
- جميع الخيارات محفوظة من خلال إعدادات المستخدم، والقيم القديمة/غير المعروفة تعود إلى `duo` و`natural` الآمنين.
- اختبار الصوت يقرأ نصًا ثابتًا ولا يعيد صياغته أو يضيف كلمات.

## التحقق الآلي

اجتازت اختبارات CI على رأس PR #123 (`c8a3c8bdf9946cb630400ae647353c597f0b4618`): **562/562 ناجحة، 0 فشل، 0 تخطٍ**. نجح Windows Release Build، وتكامل النقر والسحب وDPI ولوحة المفاتيح وGLB، والتحقق من تقارير الاختبارات، وفحوص Gitleaks وNuGet/license. اجتازت دورة المثبّت: إنشاء Setup 0.5.7، تثبيت baseline 0.5.6، الترقية إلى 0.5.7، rollback إلى 0.5.6، ثم uninstall؛ بقيت بيانات المستخدم محفوظة وأزيلت ملفات التطبيق والاختصار والتسجيل ومهمة التذكير. PR #123 مدمج في main عند `3630f6fa3d14901e603eec527a73e7140642ddab`. build run `42382693170`، security run `42382693176`.

نجاح الاختبارات الآلية لا يثبت أن جميع النبرات مسموعة كما هو متوقع على أجهزة/مزودات المستخدم، ولا يثبت إعلان قارئ الشاشة؛ قبول Windows اليدوي أدناه ما زال مطلوبًا.

## قبول Windows اليدوي المطلوب

1. بدّل بين أوضاع الشخصية الثلاثة، اختبر التوسيط وDPI، أعد تشغيل التطبيق، ثم اختبر قارئ الشاشة.
2. اختبر كل أسلوب نص بالعربية المصرية والفصحى والإنجليزية، مع طلب اختبار حساس آمن؛ تحقق من عدم تبدّل الأدوات أو تخفيف الموافقات أو حدود الأمان.
3. اسمع أصوات Realtime العشرة على المزود نفسه، واحفظ كل اختيار ثم أعد تشغيل التطبيق.
4. اختبر نبرات الإلقاء الأربع على TTS وRealtime full-duplex، بالعربية المصرية والفصحى والإنجليزية والنص المختلط. سجّل الفروقات المسموعة والتأخير.
5. اختبر Piper المحلي: سرعة النطق فقط هي المتوقع أن تختلف. تحقق من استمرار نموذج `ar_JO` للغة العربية ونموذج الإنجليزية.
6. أوقف التشغيل أثناء المعاينة وكل نبرة، وافصل مخرج الصوت، وأعد توصيله؛ يجب إيقاف التشغيل وإظهار حالة واضحة وتحرير الجهاز.
7. اختر كل محور بصورة مستقلة ثم أعد التشغيل؛ لا يغيّر أسلوب النص هوية الصوت أو نبرة الإلقاء، ولا تغيّر النبرة اختيار الصوت.

## الحالة

**BLOCKED — التنفيذ البرمجي وCI مكتملان؛ قبول Windows اليدوي للصوت وقارئ الشاشة لم يُنفذ.** لا تسجل الاستماع الفعلي أو نتائج قارئ الشاشة على أنها ناجحة بناءً على اختبارات الوحدة أو CI وحدها.
