# سجل مطابقة وظائف AYO مع مشروع ليال

**الغرض:** متابعة وظائف AYO المذكورة في مراجعة الموقع، ومقارنتها بما يوجد فعليًا في Layal. هذا سجل تتبّع تنفيذي وليس ادعاءً بأن المشروع يطابق AYO بالكامل.

**خط الأساس:** `84aefc6d5e3139d2f9f72b4b54b7d792c65c4ebe` على `main` بعد PR #80. فرع الاستكمال الحالي يضيف تسليم التذكيرات عبر Windows Task Scheduler، ونسخًا احتياطيًا اختياريًا لمحتوى ملفات محدودة مع استعادة آمنة، ومعاينة محلية لمرفقات Gmail المكتبية؛ تبقى حالتها مرتبطة بنتيجة CI وقبول Windows المحدد أدناه.

## معاني الحالة

- **موجود ومحدود:** هناك تنفيذ، لكنه لا يغطي كل سلوك AYO.
- **أُضيف في هذه الدفعة — ينتظر CI:** الشيفرة المضافة لم تثبت بعد باختبارات الفرع.
- **جزئي / قبول فعلي مطلوب:** جزء موجود ويحتاج اختبار Windows أو مزودًا/جهازًا حقيقيًا.
- **غير منفذ:** لا يوجد تنفيذ مطابق يمكن الاعتماد عليه حاليًا.
- **محجوب بخدمة خارجية:** يحتاج مزودًا أو حسابًا أو صلاحية أو موارد غير متاحة في الوضع الحالي.

## ملاحظة مهمة حول سياق السؤال السريع

تُضيف نافذة Quick Ask السؤال المكتوب إلى المحادثة الحالية وتستخدم مسار الشات المعتاد. لذلك قد يضم الطلب المرسل للمزود رسائل سابقة مختارة من سجل المحادثة وفق أداة بناء السياق وإعداد المزود، وليس السؤال الجديد وحده. لا تُلتقط الشاشة ولا تُرفق ملفات تلقائيًا من نافذة Quick Ask. إذا كان المطلوب عدم إرسال سياق سابق، استخدم محادثة جديدة وتحقق من إعدادات المزود قبل السؤال.

## ترتيب التنفيذ المقترح

1. **P0 — الوصول والتحكم:** Quick Ask والإلغاء الموحد بـ Esc؛ ينتظران نجاح CI على أحدث commit وقبول Windows. بدأ P1 بإضافة التقاط/قص الشاشة بمعاينة محلية؛ ما زال دعم لوحة المفاتيح والقبول العملي مطلوبين قبل اعتبارها مكتملة.
2. **P1 — فهم المحتوى:** التقاط شاشة بطلب صريح، Crop، Hover، محادثة الملفات وقراءة PDF/Office، مع الموافقات والحدود.
3. **P2 — البحث:** بحث ويب بمصادر وتواريخ، ثم مسار تحقق من الادعاءات.
4. **P3 — التنظيم:** أُضيفت التذكيرات المحلية مع Windows Task Scheduler، والروتينات النصية، وتذكيرات المتابعة الاختيارية. يبقى قبول Windows الفعلي مطلوبًا للنوم/الاستئناف وتسجيل الخروج والإشعارات؛ أما اقتراحات استباقية ذكية أو روتينات تنفّذ خطوات حساسة فتحتاج نموذج تهديد وموافقات صريحة قبل تفعيلها.
5. **P4 — التكاملات:** Gmail بصلاحيات محدودة، وتنزيل/رفع متصفح محكوم، ووضع الألعاب.
6. **P5 — التخصيص والخصوصية:** أُضيفت خريطة ذاكرة 3D محلية؛ يلزم قبولها وإضافة التصنيف/الأرشفة، ثم وضع Incognito، درع الخصوصية الشامل، نبرات الصوت، والثيمات والأداء.

## قواعد تمنع فقد وظيفة أو إعلان نجاح غير مثبت

- لا يُحذف أي بند من هذا السجل؛ يمكن تغيير الحالة فقط مع توثيق الدليل.
- كل وظيفة تُربط باختبار آلي أو معيار قبول Windows واضح، مع تحديد ما يحتاج API أو جهازًا أو حسابًا خارجيًا.
- لا تُرسل لقطات الشاشة أو الصوت أو الملفات إلى أي مزود سحابي تلقائيًا؛ يلزم إجراء واضح ومعلومة ظاهرة للمستخدم.
- لا يُفعّل تنفيذ سكربتات/أوامر عامة أو تكامل بريد واسع الصلاحيات قبل العزل ومراجعة الأمان.
- نجاح CI يثبت البناء والاختبارات التي نُفذت فقط، ولا يثبت قبول الميكروفون أو الكاميرا أو الاختصارات العالمية أو قارئ الشاشة أو الأجهزة الفعلية.
