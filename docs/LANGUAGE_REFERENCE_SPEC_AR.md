# مواصفة المرجع اللغوي المحلي الشامل — Layal

**الحالة:** الأساس التنفيذي v1 موجود على فرع التطوير؛ الكتالوج الحالي بذرة تحريرية صغيرة وليس قاموسًا مكتملًا.
**اللغات/التنوعات المستهدفة:** العربية المصرية (ar-EG / arz)، العربية الفصحى الحديثة (ar)، الإنجليزية (en)، والجمل المختلطة (code-switching).
**مبدأ التصميم:** المرجع يصف اللغة واستعمالها. لا يُستخدم مصدرًا للحقيقة في الطب أو القانون أو الأخبار، ولا تُخلط تعريفات المصطلحات بالمعرفة التخصصية المتغيرة.

## 1. ما الذي يحفظه المرجع؟

- المعاني والمفاهيم المترابطة بين اللغات، بدل الاعتماد على الترجمة الحرفية.
- الأشكال الكتابية والبدائل واللهجية (بما فيها الهمزات، اختلاف كتابة العامية، Arabizi، والتهجئات الشائعة).
- النطق والتحويل الصوتي وملاحظات مخارج الحروف والنبر والتنغيم عندما تتوفر بيانات موثوقة.
- نوع الكلمة، والسجل (رسمي/محايد/عامي/تقني)، والسياق التداولي، وحدود المعنى.
- أمثلة طبيعية مع ترجمة مقابلة وسيناريو الاستعمال.
- نماذج حوار متعددة اللغات، أدوار المتحدثين، وظائف الدور (طلب، استيضاح، رفض، اعتذار، إصلاح سوء فهم، إنهاء الحوار).
- شجرة موضوعات قابلة للتوسع من الحياة اليومية إلى العمل، التقنية، العلوم، الصحة، القانون، المال، السفر، الثقافة، الأمن وإمكانية الوصول.
- مصدر كل معلومة ورخصتها وإصدارها وتاريخ مراجعتها.

## 2. مخطط البيانات (Schema v1)

الملف المضمن:
src/Layal.Desktop/Resources/LanguageReference/reference.json

الكيانات:

- LanguageTopic: معرف ثابت، أب/ابن، اسم ووصف بالعربية والإنجليزية، وترتيب عرض.
- LanguageConcept: معنى عربي وإنجليزي، ملاحظة استخدام، وتصنيف موضوعي ومصدر ورخصة.
- LanguageForm: الصيغة بحسب اللغة والتنوع، كتابتها، transliteration، pronunciation، part of speech، register، variants، examples.
- LanguageDialogue: موقف حواري ونسخ متعددة اللغة واللهجة والأدوار.

تُربط أشكال اللغات بمفهوم واحد؛ لذلك يمكن عرض المصرية والفصحى والإنجليزية كمقابلات لنفس المعنى دون اعتبارها مرادفات حرفية في كل سياق.

## 3. الخدمات المنفذة في v1

LanguageReferenceService:
- تحميل الكتالوج المضمن Offline.
- التحقق من رقم schema، تفرد المعرفات، صحة المراجع الموضوعية، ووجود الأشكال.
- البحث الحتمي في الصيغ والبدائل والتحويل الصوتي والأمثلة والمعاني.
- الترشيح باللغة والموضوع وترتيب النتائج بدرجة مطابقة.
- البحث في نماذج الحوار.
- إرجاع الصياغة الأصلية للمستخدم؛ التطبيع للبحث فقط ولا يغيّر النص المعروض.

LanguageTextNormalizer:
- توحيد أشكال الألف وبعض صور الياء والكاف وإزالة التشكيل والتطويل وعلامات الاتجاه.
- لا يحاول إعادة كتابة اللهجة أو استنتاج المعنى أو تحويل العامية إلى الفصحى.
- لا يستبدل التاء المربوطة أو يطبق قواعد صرفية خطرة على البيانات الأصلية.

## 4. طبقات التوسع التالية

1. **Lexicon:** توسيع المفردات والتصريفات واللهجات والأمثلة المحررة بشريًا.
2. **Morphology:** تحليل الجذر والوزن واللواصق والضمائر وتصريف الأفعال، مع فصل الاختلافات المصرية عن الفصحى.
3. **Phonology/G2P:** تمثيل النطق الصوتي وواجهات phonemizer منفصلة حسب محرك TTS؛ لا تمرر phonemes مولدة بمحرك عام إلى نموذج متخصص يتطلب قاموسه.
4. **Dialogue pragmatics:** نية الدور الحواري، الإحالة إلى السياق، التأدب، التلميح والسخرية مع درجات ثقة وحدود واضحة.
5. **Code-switching:** وسم المقاطع داخل الجملة، حفظ المصطلح الإنجليزي، وإعادة نطقه بالصوت/اللغة الصحيحة.
6. **Domain terminology:** معاجم تقنية/طبية/مالية/قانونية وغيرها، مع تاريخ ومصدر ومراجع مراجعة.
7. **User additions:** طبقة مفردات شخصية قابلة للتصدير والحذف، تحفظ بيانات المستخدم في مخزن محمي ولا تعدّل الكتالوج الأصلي.
8. **Retrieval evaluation:** مجموعة استعلامات مرجعية ونتائج متوقعة، وقياس precision/recall ونتائج الاسترجاع السلبية.

## 5. سياسة الموثوقية والمصادر

- المحتوى الذي يكتبه المشروع بنفسه يوسم layal-curated ويُراجع في code review.
- كل مادة خارجية تحتاج URL ثابتًا، واسم ناشر، وإصدارًا، ورخصة، وحدود الاستخدام.
- لا يستورد النظام تلقائيًا محتوى من قواميس أو corpora غير واضحة الترخيص.
- مصادر الصوت لا تُستخدم للتدريب أو التضمين أو إعادة التوزيع إلا بعد مراجعة رخصة الصوت والنص وموافقة المتحدثين وشروط المصدر.
- أمثلة الحوار لا تتضمن بيانات شخصية، أو محادثات خاصة، أو نصوصًا منسوخة غير مرخصة.
- الكتالوج اللغوي ليس طبقة تنفيذ أو صلاحيات؛ لا يمكن لأي entry أو dialogue أن يضيف Tool أو ينفذ أمرًا.

## 6. معايير القبول

- تحميل الكتالوج دون اتصال وبلا HTTP.
- تطبيع البحث دون تغيير النص الأصلي.
- إيجاد صيغة مصرية مثل «إزيك» وربطها بالفصحى والإنجليزية.
- البحث داخل مصطلح تقني مختلط بالعربية والإنجليزية.
- الترشيح حسب اللغة والموضوع.
- العثور على حوار كامل في السيناريو واللغة المحددين.
- رفض schema غير معروف أو معرفات مكررة أو مراجع موضوعية يتيمة.
- لا يقدم المرجع إجابة تخصصية غير موجودة في بياناته؛ عند غياب النتيجة يصرح بذلك.

## 7. الوضع الحالي وحدود الادعاء

الإصدار الأول يحتوي شجرة موضوعات عامة (18 موضوعًا)، و20 مفهومًا تحريريًا، و3 حوارات نموذجية بثلاث صيغ. هذا يثبت البنية والبحث المحلي، ولا يعني «مرجعًا لغويًا كاملًا». المطلوب لاحقًا توسيع المفردات والحوارات على مجموعات محكمة ومراجعة بشرية، وإضافة اختبارات أكثر اتساعًا وقياس تغطية.
