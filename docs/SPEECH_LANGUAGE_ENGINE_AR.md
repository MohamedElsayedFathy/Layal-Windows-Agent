# محرك السمع واللغة والحوار — التنفيذ الأول

## النطاق

أُضيف مشروع مستقل `src/Layal.SpeechLanguage` يستهدف .NET 10 ولا يعتمد على WPF أو NAudio أو أي مزود شبكة. يوفّر:

1. عقودًا لمزودي تحويل الصوت إلى نص وتوليد الكلام.
2. واجهة تشغيل موحدة تربط التفريغ بتحليل اللغة، وتربط النص بمزود النطق.
3. اكتشافًا إرشاديًا للعربية الفصحى والمصرية والإنجليزية والنص المختلط.
4. تطبيعًا غير هدّام للنص المعروض، وتطبيعًا منفصلًا للبحث.
5. مرجعًا لغويًا بإصدار ومخطط، مع مفردات وتعبيرات ونطق وصيغ وأمثلة.
6. مرجعًا لـ14 موضوعًا حواريًا مع أسئلة افتتاحية بثلاثة أساليب لغوية.
7. تصنيفًا أوليًا لنية الحوار وسياق قصير داخل الذاكرة.
8. مستجيبًا حتميًا محدودًا لطلبات تعريف الكلمات واقتراح الموضوعات.

## الربط بالتطبيق

- يستخدم التطبيق Adapter على `LocalVoiceService` الحالي؛ تظل موارد Whisper/Piper محققة بالبصمات الحالية.
- تحويل التسجيل إلى نص يمر عبر `SpeechLanguageRuntime` ثم يُحلل النص المكتشف.
- زر التفريغ العادي ما زال يعرض النص للمراجعة ولا يرسله تلقائيًا.
- المحادثة الصوتية بالتناوب تحتفظ بتدفق الموافقة الحالي.
- نطق الردود يمر عبر واجهة المزود، مع الاحتفاظ بجهاز الإخراج ونمط الإلقاء المحددين في الإعدادات.
- يظل `MicrophoneCaptureService` ودرع الخصوصية وحدود التسجيل داخل التطبيق المضيف.

## حدود لا يجوز إخفاؤها

- اكتشاف اللهجة المصرية معجمي/قواعدي إرشادي؛ يحتاج إلى مجموعة بيانات ممثلة وتقييم WER/CER ومراجعة متحدثين متنوعين قبل وصفه بالدقة الإنتاجية.
- صوت Piper العربي الحالي أردني وليس صوتًا مصريًا أصليًا. دعم المصرية النصي لا يعني توفر لكنة صوتية مصرية.
- المرجع المدمج يضم 63 مدخلًا و14 موضوعًا كبداية قابلة للتوسع؛ لا يمثل قاموسًا شاملًا أو مرجعًا صرفيًا/نحويًا كاملًا.
- تحليل الحوار حتمي محدود ولا يدّعي فهمًا عامًا أو توليدًا مفتوحًا.
- تصنيف طلب باعتباره أمرًا لا ينفذه؛ التنفيذ يظل عبر طبقة الأدوات وموافقات التطبيق.
- القبول الفعلي للميكروفون والسماعات وجودة النطق يحتاج جهاز Windows وعتادًا حقيقيًا.

## معايير القبول

- Windows Release build ونجاح جميع اختبارات C#.
- اختبارات الفصحى والمصرية والإنجليزية والمختلطة والمرجع وسياق الحوار.
- اجتياز اختبارات Whisper/Piper الحالية وسلامة البصمات وعدم تغيير الموافقات.
- اختبار Windows عملي للميكروفون والسماعات والتسجيل والإلغاء ودرع الخصوصية.
