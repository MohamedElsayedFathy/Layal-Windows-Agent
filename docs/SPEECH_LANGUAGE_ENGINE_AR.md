# محرك السمع واللغة والحوار — الإصدار 2.0

## ما الذي تم تنفيذه

أُضيف مشروع مستقل `src/Layal.SpeechLanguage` داخل الحل. لا يعتمد المشروع على WPF أو NAudio أو Windows APIs، ويستقبل مزودي الصوت عبر واجهات. يظل التسجيل واختيار الأجهزة والصلاحيات ودرع الخصوصية في التطبيق المضيف.

### مسار السمع والكلام

- `ISpeechRecognitionProvider` و`ISpeechSynthesisProvider` واجهتان محايدتان لمزودي الصوت.
- `SpeechLanguageRuntime` ينفذ مسار التعرف ثم التحليل ومسار التحويل إلى كلام.
- يتم رفض حمولة الصوت غير الصالحة أو غير RIFF/WAVE أو التي تتجاوز 64 MiB قبل تمريرها للمزود.
- `LocalSpeechLanguageProvider` يربط Whisper/Piper الموجودين بالفعل دون شبكة أو cloud fallback.
- يبقى النص المستخرج معروضًا للمراجعة قبل الإرسال في مسار الإملاء العادي.
- لا يتغير وسيط الصلاحيات أو شروط تأكيد الأوامر بسبب تحليل اللغة.

### اللغة والتحليل

- تعرف إرشادي على الفصحى المصرية والإنجليزية والنص المختلط.
- تقسيم النص المختلط إلى مقاطع حسب السكربت.
- تطبيع محافظ للنص المرئي، مع مسار منفصل للبحث والتطابق.
- كشف نية الحوار من قوالب عربية ومصرية وإنجليزية، مع fallback حتمي محدود.
- تحليل النص يمكن أن يعيد مفردات وقواعد وموضوعات وأنماط حوار ذات صلة.

### المرجع اللغوي 2.0

ملف `Data/speech-language-reference.json` هو مصدر بيانات versioned/schema-versioned. النسخة الحالية تضم:

| فئة البيانات | العدد |
|---|---:|
| مفردات وتعبيرات | 229 |
| موضوعات حوار | 24 |
| قواعد لغوية ونحوية وصوتية وتداولية | 65 |
| قوالب قول وردود ونوايا | 66 |
| جداول تصريف الأفعال | 34 |

يغطي المرجع الاستعمالات اليومية والتعليم والعمل والوقت والسفر والتواصل والتقنية وغيرها، ويحتوي على أمثلة عربية فصحى ومصرية وإنجليزية. ولا يُعرض على أنه قاموس شامل؛ فكل لغة ولهجة تحتوي على مفردات واستعمالات لا يمكن حصرها في إصدار واحد.

### واجهات الاستعلام

- `Find`: المفردات والصيغ والمرادفات.
- `FindGrammar`: القواعد حسب النص واللغة والفئة.
- `FindVerbParadigms`: الأفعال وصيغها.
- `FindDialoguePatterns`: العبارات والردود بحسب الموقف ونية الحوار.
- `FindTopics`: موضوعات وأسئلة افتتاحية.
- `GetCoverage`: إحصاءات نسخة المرجع.

### تكامل واجهة Layal

- تم حقن `LocalSpeechLanguageProvider` في النافذة الرئيسية.
- يمر التفريغ ونطق الردود عبر Runtime الموحد.
- يظل اختيار جهاز الصوت ونمط الإلقاء من الإعدادات الحالية.
- يضيف `NativeConversationEngine` إجابات محدودة من المرجع لطلبات معنى كلمة أو شرح قاعدة أو تصريف فعل أو اقتراح عبارة أو موضوع.
- لا يملك المحرك حق تنفيذ الأوامر، ولا يتجاوز الموافقات.

## حدود الجودة والقبول

1. اكتشاف اللهجة المصرية نصي/معجمي وليس نموذجًا صوتيًا إحصائيًا؛ يحتاج تقييمًا على مدونة كلام ممثلة وقياس الدقة والالتباس.
2. صوت Piper العربي الحالي أردني. لم تتم إضافة صوت مصري أصلي، ولا يصح ادعاء نطق مصري قبل اعتماد نموذج صوتي مناسب وترخيصه واختباره.
3. البيانات الحالية مرجع يومي واسع قابل للمراجعة والتوسعة وليست حصرًا شاملًا لكل المعجم أو النحو.
4. التحليل حتمي محدود، وليس نموذج فهم مفتوحًا أو مولد حوار عام.
5. الاختبارات الآلية لا تعوض تجربة الميكروفون والسماعات على أجهزة Windows حقيقية.

## معايير التحقق

- Release build على Windows.
- اختبارات تحليل اللغة والنية والمرجع اللغوي ومزودي الصوت.
- اختبارات خدمات Whisper/Piper القائمة وسلامة بصمات مواردها.
- اختبارات الخصوصية والإلغاء والتنقل وإمكانية الوصول الحالية.
- اختبار يدوي منفصل للميكروفون والسماعات وجودة النطق واللهجة.
