# تقرير الفحوص الساكنة — Layal 0.5.2

## الفحوص التي نُفذت في بيئة التأليف

- `python tools/validate_project.py` — PASS.
- `python tools/validate_release.py` على شجرة المصدر — PASS.
- تحليل ملفات XAML كـ XML — PASS.
- فحص مفاتيح موارد التصميم وأسماء عناصر الواجهة ومعالجات الأحداث — PASS.
- فحص توازن الأقواس في ملفات C# للمصدر والاختبارات — PASS.
- فحص وجود مشروع الاختبارات وإعداداته ووجود خمس مجموعات اختبار — PASS.
- فحص الأنماط الشائعة للأسرار — PASS بعد تعديل قيمة اختبارية كانت تشبه نمط مفتاح API.

## الفحوص التي لم تُنفذ

- `dotnet restore`, `dotnet build`, `dotnet test` — NOT RUN؛ لا يوجد .NET SDK مثبت في بيئة التأليف، كما تعذر الوصول إلى الإنترنت لتنزيله.
- تشغيل واجهة WPF والاختبارات التي تستخدم Windows DPAPI — NOT RUN؛ تحتاج Windows/.NET SDK.
- اختبار اتصال بمزود حقيقي أو اختبار ميكروفون/كاميرا أو النافذة العائمة فوق سطح مكتب فعلي — NOT RUN.

## ما الذي يعنيه هذا؟

نجاح الفحوص الساكنة يثبت فقط سلامة مجموعة محددة من ملفات المصدر والموارد والتكوين. لا يثبت أن C# يجمع بنجاح أو أن الاختبارات تعمل أو أن ميزات Windows تعمل وقت التشغيل. لا ينبغي تغيير حالة أي متطلب إلى «متحقق» حتى تظهر نتيجة بناء واختبارات ناجحة على Windows CI أو جهاز Windows موثق.
