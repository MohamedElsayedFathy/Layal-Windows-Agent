## ملخص القبول

- حالة UI-00: **Pending** حتى اكتمال المصفوفة والتفاعلات المطلوبة.
- العيوب المرصودة: لا شيء مسجل بعد.
- فحوص لم تتوفر بيئتها: لا شيء مسجل بعد.
- روابط الصور/الفيديو الأصلية: لا شيء مسجل بعد.
- القرار: **Pending**.

### قواعد التسجيل

1. استخدم `Pass` أو `Fail` أو `Pending` لكل بند مع ملاحظة موجزة.
2. أرفق دليلًا فعليًا للنجاحات والإخفاقات؛ لا تعتبر تنفيذ الإجراء وحده نجاحًا.
3. لا تضع علامة `Pass` إذا لم يعمل التطبيق أو لم يتوفر إعداد الاختبار.
4. لاختبار DPI أو الشاشات المتعددة، سجّل الأجهزة والإعدادات الفعلية؛ إذا لم تتوفر فابقِ الحالة `Pending`.
5. بعد الإصلاح، أعد الفحوص المتأثرة على commit جديد وسجّل رقم commit الجديد.
