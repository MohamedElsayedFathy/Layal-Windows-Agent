# تحويل الكلام إلى نص — STT

## الاستخدام

1. افتح تبويب **المحادثة** واضغط **تسجيل صوت**.
2. وافق على تشغيل الميكروفون. التسجيل لا يبدأ قبل هذه الموافقة.
3. تحدث بالعربية الفصحى أو العامية المصرية أو الإنجليزية، ويمكن خلط العربية والإنجليزية في الجملة نفسها.
4. اضغط **إيقاف وتحويل** عند الانتهاء؛ سيتوقف التسجيل تلقائيًا بعد دقيقتين.
5. راجع نافذة تأكيد إرسال التسجيل إلى موفر API. اختيار **لا** يتخلص من الصوت دون رفعه.
6. بعد التحويل، يظهر النص في حقل الرسالة للمراجعة والتعديل. لا يتم إرسال الرسالة تلقائيًا؛ اضغط **إرسال** فقط عندما تكون جاهزًا.

## إعداد النموذج

من الإعدادات، احتفظ بعنوان API ومفتاحه الحاليين وأدخل **معرّف نموذج تحويل الكلام إلى نص (STT)**. الإعداد الافتراضي هو `gpt-transcribe`. هذا النموذج يستخدم في نقطة النهاية `/audio/transcriptions`، وقد يختلف عن نموذج المحادثة النصية. يجب أن يدعم موفر API المستخدم نقطة النهاية ونموذج STT؛ التوافق مع OpenAI Chat Completions لا يضمن دعم الصوت.

## اللغات واللهجة

تُرسل تلميحات اللغة `ar` و`en` مع توجيه للحفاظ على العامية المصرية والكلمات الإنجليزية التي يقولها المستخدم دون ترجمتها أو تحويلها للفصحى. هذه تهيئة للنموذج وليست ضمانًا للدقة؛ اختبر أسماء الأشخاص والأرقام والعبارات المختلطة في بيئة الاستخدام الفعلية.

## الخصوصية والأمان

- التسجيل يدوي ولا يوجد استماع مستمر.
- لا تُكتب التسجيلات الخام إلى القرص؛ تُحتفظ مؤقتًا في الذاكرة وتُمسح عند الإلغاء أو بعد محاولة التحويل.
- يبدأ استخدام الميكروفون بعد موافقة منفصلة، ورفع التسجيل يحتاج موافقة أخرى بعد التوقف.
- تُرفض روابط HTTP غير المحلية؛ الإرسال إلى موفر بعيد يجب أن يستخدم HTTPS. يسمح بـ HTTP فقط مع عنوان loopback محلي مثل `http://127.0.0.1`.
- مدة التسجيل القصوى دقيقتان، وتُستخدم صيغة WAV أحادية القناة 16 kHz / 16-bit PCM.
- لا تضع مفتاح API داخل عنوان URL. استخدم حقل المفتاح المحمي في إعدادات Layal.

## حدود الإصدار الأول

هذه المرحلة تضيف إدخال الكلام كنص للمراجعة. لا تتضمن توليد الكلام (TTS)، أو الاستماع الدائم، أو محادثة صوتية لحظية، ولا تُلغي القيود التي قد يفرضها موفر الخدمة.
